# Image pipeline

Mechanics only. When an image earns its place, and the rules about what it may depict, are in SKILL.md.

## The contract

The page declares a map and a stub; the script fills the stub:

```js
var IMGPROMPTS = {
  hero:    "A dim room lit only by birthday candles, a hand blurred as it reaches in",
  portrait:"https://commons.wikimedia.org/wiki/Special:FilePath/Example.jpg?width=800"
};
var IMAGES = /*__IMG__*/{};
```

```
node scripts/images.mjs <lesson.raw.html> [out.html] [--key-file <path>] [--quality low|medium|high]
```

Same shape as `tts.mjs`. A value that is a **prompt** is generated; a value that is a **URL** is fetched. Output is `{id: "data:<mime>;base64,…"}`, so the lesson stays self-contained.

**Never blocks a build.** With no key and nothing but prompts, the stub is left alone and the page keeps its CSS placeholder. A fetch-only run needs no key at all.

**Cached** in `<lesson dir>/images/` — generated by a hash of `model|quality|size|prompt`, fetched by a hash of the URL, so a rebuild only re-does what changed. Each fetched file gets a `.lic.json` sidecar carrying its licence, because on a cache hit the licence API is never called and without it a rebuild would skip the attribution check.

**Budget** ~0.1 MB per image against the lesson's ~15 MB total.

## Fetching from Wikimedia Commons

Find candidates without guessing filenames:

```
node scripts/images.mjs --search "apollo 11 launch"
```

One API call, results already filtered to PD/CC0/CC BY, printed as paste-ready URLs with the credit line where one is owed. Guessed filenames 404; searching the era rather than the subject's memorial is what surfaces the historical images (see the survey below).

Use the `Special:FilePath` form:

```
https://commons.wikimedia.org/wiki/Special:FilePath/<File name>?width=800
```

The `upload.wikimedia.org/wikipedia/commons/thumb/...` URL that looks more natural **returns 400**. Spaces in the file name are fine. The script sends a descriptive user-agent because Wikimedia rejects bare tool names under its UA policy.

### Licences — enforced, not advisory

Allowed: **Public Domain · CC0 · CC BY**. Everything else is refused, dropped from the page, and its cache entry deleted:

- **CC BY-SA is refused** by policy — share-alike deters reuse, and annotating an image would produce adapted material.
- **An unreadable licence is refused too.** The lookup retries once; if it still fails the image is dropped. The lookup fails transiently, and embedding a picture whose terms nobody could read is worse than losing it.

**CC BY requires credit, and the script checks the page for it.** After writing the output it looks for the author *and* the licence name in the delivered HTML, and exits `1` if either is missing. Put the credit in the caption or a credits line:

```html
<figcaption>Elon Musk. Photo: Steve Jurvetson, CC BY 2.0</figcaption>
```

The check compares against the real author from the file's metadata, so a plausible-but-wrong credit fails.

Reading the console output is the fastest way to see where you stand:

```
musk ← …/Special:FilePath/Elon Musk 2015.jpg … 236KB
   licence: CC BY 2.0 — CREDIT REQUIRED: "Steve Jurvetson, CC BY 2.0"
bush ← …/Special:FilePath/George-W-Bush.jpeg … 253KB
   licence: Public domain

attribution present for 1 CC BY image(s)
```

### What availability actually looks like

Sampling the first dozen Commons hits per subject:

| subject | usable |
|---|---|
| George W. Bush | 12 / 12 |
| Elon Musk | 10 / 12 |
| Challenger disaster | 1 / 6 |
| Chiang Kai-shek | 1 / 12 |

US government work is public domain by statute, so presidents and NASA are clean. The two poor results are not about the subject being obscure — the searches returned modern tourist photographs of memorials, which are almost all CC BY-SA, while the historical images themselves (the explosion, the Cairo Conference) are public domain. Search the event or the era, not the monument.

## Generation

Model defaults to `gpt-image-1` (override with `IMAGE_MODEL`), 1024×1024, WebP at quality 70. The key comes from the environment, a `.env` searched upward from the lesson folder, or `--key-file`. Never from a conversation.
