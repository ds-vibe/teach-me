# Reference screenshots

Study the images, not the filenames. Each anchors a specific dimension of the quality bar — open the ones matching the thing you are about to build or judge.

- `lesson-hero-dutch.png` — Bold-concept hero band: subject-derived look (Soviet-poster type for a chess opening), h1 + lede left, playable subject visual right, stat strip. Note the plain topbar and the "Watch · 15 seconds" device label.

- `lesson-watch-then-play-dutch.png` — Skills practiced in their own medium: worked example ("Watch · The setup, move by move") beside the same board as the learner's task ("Your move · Play it back"), one component serving demo and practice.
- `lesson-card-anatomy.png` — Concept card anatomy: rule id eyebrow · plain title · one-line gist · "Why this exists" with Listen · verbatim rule text with operative phrases highlighted · on-the-record example · FRE↗ source link.

- `lesson-diagram-grammar.png` — Decision-diagram grammar: drawn connectors terminating at targets, labeled YES/NO exits, color-coded outcome pills used consistently, gold dashed edges marking the direction flip, annotation card at the flip, honest footnote on scope.

## A note on what is here

This set is deliberately small — a few anchors per dimension, not a gallery. Open two or three that match what you are about to build. Reading all of them costs more context than it returns, and none of them are used at runtime: they exist to set the bar, not to be copied.
